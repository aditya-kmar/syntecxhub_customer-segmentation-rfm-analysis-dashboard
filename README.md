# syntecxhub_customer-segmentation-rfm-analysis-dashboard
Customer Segmentation (RFM) Analysis Dashboard built in Power BI using AdventureWorks data. This interactive dashboard analyzes customer behavior through Recency, Frequency, and Monetary Value (RFM), providing customer demographics, segment-wise sales insights, customer details, and marketing recommendations for data-driven decision making
# 📊 Customer Segmentation (RFM) Analysis Dashboard | Power BI

## 📌 Overview

This project is an interactive **Power BI dashboard** built using the **AdventureWorks Dataset** to perform **RFM (Recency, Frequency, Monetary Value) Analysis**. The dashboard segments customers based on purchasing behavior and provides valuable business insights to support customer retention, targeted marketing, and data-driven decision-making.

---

## 🎯 Objectives

- Analyze customer purchasing behavior using the RFM model.
- Identify high-value and loyal customers.
- Understand customer demographics and sales distribution.
- Support marketing teams with customer segmentation strategies.
- Enable interactive business reporting through Power BI.

---

## 📊 Dashboard Pages

### 1️⃣ Customer Demographics
- Total Sales KPI
- Total Customers KPI
- Sales by Gender
- Sales by Marital Status
- Sales by Age Band
- Sales by Country (Map)
- Product Name Filter

---

### 2️⃣ Customer Segmentation (RFM)
- Number of Customers by Segment
- Total Sales by Segment
- Recency Analysis
- Frequency Analysis
- Monetary Value Analysis

Customer Segments Included:
- Champions
- Loyal Customers
- Potential Loyalists
- New Customers
- Promising
- Need Attention
- About To Sleep
- At Risk
- Cannot Lose Them
- Hibernating Customers
- Lost Customers

---

### 3️⃣ Customer Details
- Customer ID
- First Name
- Last Name
- Email Address
- Marital Status
- Age
- City
- Country
- Total Sales
- Customer Segment

---

### 4️⃣ Segment Description & Marketing Actions
This page explains:
- Recency (R)
- Frequency (F)
- Monetary Value (M)

It also provides recommended marketing strategies for every customer segment.

## 📈 Key Insights

- Identified high-value customers using the RFM model.

- Analyzed revenue contribution by each customer segment.
